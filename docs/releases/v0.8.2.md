Polaris can now trace itself. Turn on **Developer mode** in Settings → About and the daemon, the Desktop App and the iPhone app send their own traces to the Traces view, while the Data view opens SQLite databases, including the daemon's own.

## What's new

### Developer mode

- **One switch for all your hosts.** Settings → About → **Developer mode** turns it on for every connected host, applies at once with no restart, and is off by default. The iPhone app shows it in Settings.
- **Polaris traces itself.** With developer mode on, the daemon, the Desktop App (main process and window) and the iPhone app each send traces, named by component. A request carries its trace across from the app to the daemon, so the click that sent a command and the daemon work it caused are one trace.
- **Where the traces appear.** Self-traces belong to your Polaris workspace, found by its git remote, and show in Traces in each of its checkouts. Settings → About shows which workspace each host uses, with a picker to choose another. With no Polaris workspace, Traces offers **Show Polaris's self-traces**.
- **Bounded.** Self-traces keep about 50 MB or 24 hours on each host. While a host is unreachable, an app holds at most 1 MB or five minutes of them and drops the oldest. Nothing leaves your hosts.
- **The daemon's databases in Data.** With developer mode on, the daemon's SQLite files (state, traces, usage and the rest) appear in Data as read-only data sources marked **DAEMON**. Agents can query them only in checkouts of the Polaris workspace.

### Data (⌘4)

- **SQLite.** Data opens SQLite files as data sources, found from `.env` files and Prisma and Drizzle `file:` URLs, or added by path. SQLite is read-only for now.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.8.2-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.8.1 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.8.2 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.8.2-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.8.2 the next time it connects.

## Known limitations

- With developer mode on, an idle daemon uses about 50 MB more memory, because the trace store stays open.
- SQLite data sources can't be written to yet, and extensions don't send self-traces.
- The Raycast extension and Polaris SDK 0.2.0 aren't in this release; they follow in a later one.
- 0.8.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.8.0) still apply.
