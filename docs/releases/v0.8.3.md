Data finds more of your databases and connects to ones that need TLS, SQLite tables open again, and developer mode's self-traces keep their parents. Agents working on Polaris can now read those self-traces too.

## What's new

### Data (⌘4)

- **Monorepos.** Data source discovery now reads each package in a monorepo, not just the checkout root, so a Prisma schema or `.env` in `packages/db` shows up. A package's sources are prefixed with its folder (`packages/db/…`); sources at the root keep their names.
- **Paste a connection string.** Pasting a `postgres://`, `mysql://` or `file:` URL into a new data source's Host or File field fills in the engine, host, port, database, user and password.
- **TLS for manual data sources.** A data source you add by hand has a **TLS** setting (libpq's `sslmode`, from disable to verify-full), so Neon, PlanetScale and other servers that require TLS connect. A pasted connection string's `sslmode` sets it.

### Workspace bar

- **Collapse a host.** Click a host's name in the workspace bar to collapse its workspaces, and again to expand them. ⌃1–⌃0 then skip the collapsed host's workspaces. A collapsed host still shows its state, how many workspaces it has, and whether a session there needs you. The workspace you have open stays visible. Collapsing applies only on this Mac.

### Developer mode

- **Agents read Polaris's own traces.** In the Polaris workspace with developer mode on, the `traces`, `trace` and `span` tools accept `scope: "self"`. `trace` and `span` also find self-traces by id without it.

## What's fixed

- **SQLite tables open in Data.** Opening a SQLite table no longer fails with "This table does not exist in this SQLite file".
- **Self-traces keep their parents.** The Desktop App could stop sending its traces to the daemon after a lost reply, leaving daemon spans marked "parent not kept". A send that gets no answer now gives up after 30 seconds and is retried, and a busy trace store retries the batch instead of dropping it.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.8.3-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.8.2 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.8.3 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.8.3-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.8.3 the next time it connects.

## Known limitations

- Long-lived feeds (watches and session subscriptions) still show "parent not kept" in self-traces, because their app-side span ends only when the feed closes (ENG-732).
- SQLite data sources can't be written to yet, and extensions don't send self-traces.
- 0.8.2's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.8.2) still apply.
