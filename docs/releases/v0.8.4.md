Data's tables open again, the SQL editor sees your schema, and you can browse a remote data source before you approve it for agents.

## What's fixed

### Data (⌘4)

- **Tables open.** Clicking a table opened a tab stuck on "Loading rows…" and its Structure view stayed empty. Its rows and structure now load.
- **The SQL editor knows your schema.** Table and column completions in an SQL tab never loaded. They load now.
- **Browse a remote data source before you approve it.** Clicking a remote data source that agents can't reach yet did nothing. It now opens and shows its tables. It keeps its lock and "Agents can't reach it until you approve it.": approval controls what agents can reach, not what you can browse. Unapproved sources still start closed.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.8.4-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.8.3 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.8.4 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.8.4-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.8.4 the next time it connects.

## Known limitations

- 0.8.3's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.8.3) still apply.
