A fixes release for 0.8.0: the daemon starts lighter, and Windows hosts get Data and Traces fixes.

## What's fixed

### Your hosts

- **A lighter daemon.** Data, Traces, CPU profiles and the iPhone relay now load the first time something uses them, so an idle daemon starts with about 140 fewer modules and uses less memory.
- **CPU profiles read more recordings.** A Node profile whose samples arrive slightly out of order now opens instead of failing, and the largest profiles use less memory to read.

### Windows hosts

- **Data:** data source paths under your home folder show as `~\…`, and saved data sources are readable only by your user.
- **Traces:** **Restart with profiling** stops the profiled server and everything it started when the recording ends.
- **Private files** an agent session writes, such as its browser configuration, are readable only by your user, and a failed write no longer leaves a copy behind.
- A connection that closes while the daemon is reading from it no longer crashes the daemon.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.8.1-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.8.0 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.8.1 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.8.1-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.8.1 the next time it connects.

## Known limitations

- The Raycast extension and Polaris SDK 0.2.0 aren't in this release; they follow in a later one.
- 0.8.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.8.0) still apply.
