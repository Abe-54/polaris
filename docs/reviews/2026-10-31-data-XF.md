## Memory probe

RX's original probe source was run in fresh Bun processes against the Lead's disposable
Postgres 16/MySQL 8.4 databases. Sampling is process RSS at 5 ms intervals, not a quiet-host
benchmark or a bound on database-server memory. Rounded deltas from this run:

| Payload | Postgres RSS delta | MySQL RSS delta |
| --- | ---: | ---: |
| 17 MiB cell | 0 MiB | 0 MiB |
| 100 MiB cell | 0 MiB | 0 MiB* |
| 20 × 10 MiB cells | 1 MiB | 0 MiB |
| 1 KiB rows, requested limit 10,000 | 10 MiB | 18 MiB |

All measured deltas are below the 64 MiB acceptance budget. The large-row cases return 992
rows and approximately 1.02 MB across four protocol chunks. Cells return a 128-character
Truncated preview. *MySQL itself returns NULL for the 100 MiB expression because it exceeds
its packet setting, so that case does not establish transfer of a 100 MiB MySQL value.
Exact probe output: [memory.txt](2026-10-31-data-XF/memory.txt).
RX's earlier measurements were +101/+95 MiB for 17 MiB cells, +803/+551 MiB for 20 × 10 MiB,
and +113/+144 MiB for the requested 10,000 narrow rows (Postgres/MySQL respectively).
