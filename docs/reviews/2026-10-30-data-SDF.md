## MySQL profile and idle comparison

On one disposable 5,000-table fixture, before: 7,361 ms total, including 5,522 ms
joining TABLE_CONSTRAINTS/CHECK_CONSTRAINTS and 1,140 ms on InnoDB identities.
Bounded table names alone left the join at 5,520 ms. Separate bounded constraint
and CHECK reads reduced those steps to 20 + 20 ms, with a 1,578 ms total. A second
capture on the same fixture took 1,309 ms; its database was dropped afterwards.
The final C1 fresh-fixture run took 1,388 ms: tables 195, columns 157, indexes 41,
constraints 24, CHECK clauses 20, objects 14 and identities 847 ms. Query limits,
row estimates, and the 30-second deadline were not weakened. Physical Pi timing
remains unmeasured.

The clean dispatch base was also measured in a temporary detached worktree with
its own Polaris sources and the installed pinned third-party dependencies. Both
runs used three samples against the unchanged saved Host baseline:

The SDF idle run predates the accepted W merge and final narrow decoder/retention guards.

establish a quiet-Host memory acceptance. The baseline is unchanged; no idle
polling, watcher or timer was introduced. The temporary worktree was removed.
