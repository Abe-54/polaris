Sixteen targeted mutations removed retention, deduplication, target staleness,
concurrency flags, stable identity, index ordering, generated metadata, per-table
truncation, late labels, parallel capture, adjacent lookup, push detection,
uncertain row counts, discovery caching, text scrubbing and real error mapping.
Every mutation caused its named regression to fail; each original was restored.

## Verification and limits

- Data/Engine/transport/protocol/Client checks: 916 pass, 18 platform/service/opt-in skips, 0 fail before the W seam.
- Native identity/wide-table/expression/index/view/trigger/redaction regressions: both engines pass; existing migration fixtures pass on both engines.
- The new `data_snapshots` Quint module models target revisions, carry provenance, adjacent ends, user invalidation and concurrent-writer uncertainty. Session commit/ack transitions stay unchanged.
- Sandbox-only Data runs failed eight socket/listener checks. The approved native rerun passed; those sandbox failures are not product failures.
- Initial native regressions exposed an escaped MySQL literal and a PostgreSQL view-fixture column rename. Both were corrected and rerun successfully.
- Idle comparison was run with three samples against the unchanged committed Host baseline. It reported 7.4 busy background cores; CPU/wakeups passed, while client RSS, client footprint and no-client footprint exceeded that old baseline. A same-base comparison is recorded separately below. No timer was added and no baseline was loosened.
- Unknown scripts/writers, nontransactional multi-query catalog changes, and catalog objects listed outside coverage in the Data README remain observational limits.
- Apalache and physical Raspberry Pi measurements are not claimed.
