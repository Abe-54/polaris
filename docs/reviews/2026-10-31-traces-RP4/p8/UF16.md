## Execution and ingest

Comparisons run on demand in the trace worker. Each file-backed comparison owns
a private WAL read transaction, so ingest and other reads can progress between
chunks without changing its snapshot. Rollback and close run in `finally`.
There are no idle timers, sample caps, or Baseline truncation.

Candidate paging happens before root/time filtering, including when every row is
excluded. Single-Turn lookup uses `summaries_turn(checkout,turn_id,trace_id)`;
range and Baseline scans use primary-key order. Semantic lookup reuses
`spans_history_covering` and its name/parent-name columns, with service and
before-membership checked per row. It yields after bounded cursor batches.

Root refresh first uses a small partial index, `spans_parentless`, avoiding JSON
parsing of every child in the common parentless-root case. A remote-root/earliest
fallback handles other traces. An exploratory extra per-Span signature index
was removed after a matched run exposed ingest overhead. The final design does
not add that index to every Span write.
