## Declined: P5-12

The finding was "Update it in Settings → Hosts can't help": no Daemon advertised `traces.profiles`, so the upgrade would do nothing. Since P4 (merged at `be22ec7e2`, in this base), the Daemon advertises `traces.profiles` (`apps/daemon/src/transport/serve.ts:254`) and serves `profiles.watch`, `profiles.get` and `profiles.restartWithProfiling` (`ProfilesRpcsLive`). A throwaway Daemon from this branch said so over the socket, and answered a `profiles.watch` for an unknown session with a `ProfileError` rather than `Unsupported` (see the UF5 claim's receipts). The message now shows only on a Host whose Daemon predates P4, and for that Host, updating the Daemon in Settings → Hosts is the fix. The copy stays.
